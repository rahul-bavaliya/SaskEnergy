# P-006 Lessons Learned

The refresh was completed with limited disruption and produced a strong customer-facing result. Finish mockups helped the owner make quick visual decisions, and fixture installation was coordinated efficiently around merchandising needs.

The main variance came from owner-driven finish upgrades. After reviewing mockups, the owner selected premium flooring, an accent wall finish, and added dimming controls for display lighting. These changes were manageable, but they increased cost relative to the original small project budget. Minor delays also occurred because owner approvals were needed during a short schedule.

For future cosmetic retail refreshes, estimators should confirm finish standards, lighting control expectations, signage scope, and owner approval deadlines before finalizing a budget. A small contingency can disappear quickly when the owner changes visible finishes late.

This project is intentionally tricky as a comparator. It contains retail keywords like lighting, fixtures, signage, and finishes, but it lacks major demolition, HVAC modifications, electrical panel upgrades, washroom work, POS infrastructure, and commissioning. An AI-assisted tool should avoid over-ranking it for a larger suburban retail build-out simply because the vocabulary overlaps.
